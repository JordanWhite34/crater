# Synthetic unlabeled batch v2

Twelve new wide, field-documentation-style Humvee images generated with heavy
reference to the real military image collection. They use varied roadside,
wooded, snowy, rural, industrial, and recovery environments and remain
unlabeled pending CVAT review.

Sampling targets follow the held-out diagnostics: 4 communications-equipment,
3 weapon-station, 2 structure, 2 mobility, and 1 engine-bay image. The target
state is planning metadata only, not a final annotation.
