# DVIDS Humvee supplemental set

Three batches of 100 unlabeled DVIDS photographs (300 total) are included as supplemental CRATER vehicle-part data. Images were selected for a prominent HMMWV/Humvee or visible vehicle components, with a mix of exterior, maintenance, terrain, recovery and damage scenes. The third batch adds more component views and field conditions, including a few elevated or long-range vehicle views where available.

## Fit for the intended model

DVIDS searches did not yield a large group of clear, single-Humvee top-down or drone-view photographs. Most images in both batches are eye-level or low-oblique views; the sling-load photographs add elevated/airlift context but are not substitutes for drone footage. Use this collection for supplemental vehicle-part visibility, condition and background coverage. Some images include people, background vehicles, partial cropping or component-focused framing; MANIFEST.csv records curation notes to guide review before annotation.

## Contents

- images/: 300 JPEGs. Most are originals downloaded through each DVIDS page Download Photo control; one image uses a 2000-pixel DVIDS derivative because its original-download endpoint failed. One MPO download was converted to a single-frame JPEG. MANIFEST.csv records DVIDS-reported original dimensions and flags the derivative resolution difference in its curation note.
- MANIFEST.csv: DVIDS photo IDs, source URLs, credits, resolution and curation notes.
- Annotation status: none. This set is unlabeled; no train/validation/test split has been assigned.
